KRAKATOA ADMIN
Conectá el admin con tu repo de GitHub. Cuando guardes un producto, el admin actualiza productos.json en el repo y la web se actualiza sola.
Cómo crear el token (una sola vez)
  1. Entrá a github.com/settings/personal-access-tokens/new
  2. Token name: "Admin Krakatoa". Expiration: 1 año.
  3. Repository access: "Only select repositories" → elegí Krakatoa.
  4. Permissions → Repository permissions → Contents: "Read and write".
  5. Tocá Generate token, copialo y pegalo acá arriba. GitHub no te lo vuelve a mostrar.
